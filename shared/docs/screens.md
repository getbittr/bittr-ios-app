# Screen inventory

Walked from iOS as the source of truth. Each screen lists its purpose, key states, and the Maestro flow that exercises it. Screenshots auto-generated by Maestro into `screenshots/<flow>/<step>.png`.

Coverage below reflects what's been walked so far; more screens land here as flows expand.

## Format

```
### <Screen name>

- **VC**: `ios/bittr/<path>/<File>ViewController.swift`
- **Purpose**: one-line description
- **States**: empty / loading / synced / error / pending / ...
- **Flow**: `shared/flows/<flow_name>.yaml`
- **Screenshots**: `shared/docs/screenshots/<flow_name>/`
```
